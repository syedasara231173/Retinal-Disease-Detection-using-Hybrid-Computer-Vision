# Retinal-Disease-Detection-using-Hybrid-Computer-Vision
Hybrid Computer Vision and DINO Vision Transformer for Explainable Diabetic Retinopathy Detection using Retinal Fundus Images.
## 🏗️ System Architecture

The proposed framework integrates traditional computer vision with self-supervised representation learning using DINO Vision Transformer.

## 🧠 Explainable AI

To improve transparency, attention maps are generated from the DINO Vision Transformer, allowing visualization of retinal regions contributing most to the final prediction.

This helps clinicians understand the model's decision-making process.
